# Vesta Dairy OS

A modern, responsive supply chain operations portal built for **dairy industry workflows**. Vesta Dairy OS streamlines QR and barcode-based processes including receiving, putaway, product lookup, traceability, and operational monitoring.

> **Note:** Vesta Dairy OS is a **vibe-coded project** created for simple operational use cases and rapid workflow improvement. The primary goal is to reduce repetitive manual steps and make everyday processes faster, simpler, and easier to manage.

## ⚡ Getting Started

### Prerequisites

Make sure you have the following installed:

* **Node.js 18+**
* **npm**

### 1. Clone the repository

```bash
git clone https://github.com/RootGokul-404/qr-generator
cd 
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available through the Vite development server, typically at:

```text
http://localhost:3000
```

### 4. Build for production

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```

## 🧭 Core Workflow

Vesta Dairy OS is designed around a simple operational flow:

```text
Receiving
   ↓
QR / Barcode Scanning
   ↓
Product Identification
   ↓
Putaway
   ↓
```

## 💡 Project Philosophy

Vesta Dairy OS follows a **vibe-coding and rapid-prototyping approach**.

It was built to explore how lightweight software and modern AI-assisted development can quickly solve **simple, repetitive operational problems** without introducing unnecessary complexity.

The project focuses on:

* ⚡ **Faster processes** — Reduce the time required for routine tasks
* 🧩 **Simple use cases** — Solve focused operational problems
* 🔄 **Less manual work** — Reduce repetitive data entry and lookup
* 📱 **Easy interaction** — Keep workflows straightforward for operators
* 🚀 **Rapid development** — Quickly turn operational ideas into working tools
* 🔍 **Practical experimentation** — Validate ideas before investing in larger systems

This project is **not intended to replace a full enterprise supply chain management system**. It is better suited for lightweight workflows, demonstrations, internal tools, prototypes, and simple operational use cases.
