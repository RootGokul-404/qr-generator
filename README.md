# Vesta Dairy OS

A modern supply chain portal for dairy operations, built with React, TypeScript, and Vite. This app supports QR and barcode workflows for receiving, putaway, product lookup, history tracking, and operational visibility.

## Features

- Dashboard overview for operations
- QR code generation
- Bulk QR code generation
- Sequence QR creation
- Pigeon-hole QR workflows
- QR and barcode scanning
- Receiving and putaway tracking
- Product search and lookup
- QR and barcode history
- Notification support and operator settings
- Responsive dark-themed interface

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- HTML5 QR Code
- JsBarcode
- QRCode

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

The app runs on the Vite development server, usually at:

```bash
http://localhost:3000
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Notes

This application is designed for dairy supply chain operations where fast scanning, item traceability, and clear operational workflows are essential.
